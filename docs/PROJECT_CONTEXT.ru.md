# Контекст проекта из доступной переписки

Подтверждено пользователем:

* Прошивка — Betaflight.
* Инструмент анализирует полётные Blackbox-логи и предлагает исправления фильтров,
  PID и связанных настроек, с объяснением причин.
* До анализа уточняются желаемый отклик (резкий/плавный), наличие груза и условия борта.
* Нужна опора на документацию и экспертные материалы, с видимыми источниками.
* Инструмент предназначен для нескольких пользователей, а не одного личного борта.

В этой переписке пока **не предоставлены** реальный лог, `diff all` / `dump all`,
версия установленного Betaflight, модель FC/гироскопа, масса конкретного борта,
моторы/винты и ранее подобранные значения PID/фильтров. Утверждать, что они известны,
или объявлять демопример пользовательской настройкой нельзя.

Для первого проверенного исходного профиля нужны файл полёта и конфигурация с
того же борта/прошивки/PID-профиля. Ранее настроенный профиль можно использовать
как персональную точку сравнения, но нельзя превращать в дефолт для всех пилотов.

Текущая реализация — локальный браузерный MVP без регистрации и бэкенда.
Публичный хостинг не опубликован. Сохранение профилей локальное для каждого браузера.
